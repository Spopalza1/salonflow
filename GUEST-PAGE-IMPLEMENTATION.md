# Guest Page Implementation

Implemented in this package:

- Premium translucent Liquid Glass guest shell shared by welcome, choice, message, and menu screens.
- Salon media remains visible behind a controlled blurred veil instead of an opaque background.
- Ambient, low-motion visual lighting for a polished landing experience.
- Smooth fade, blur, scale, and vertical transitions between guest views.
- Refined first-name and last-name welcome card matching the main SalonFlow landing experience.
- Refined guest choice cards with premium glass depth and hover feedback.
- Guest message and menu views now enter with the same transition language.
- Removed automatic focus from guest name and message fields to prevent the mobile keyboard opening unexpectedly.
- Required/optional customization badges remain hidden in guest mode while validation rules continue to be enforced internally.

Protected behavior preserved:

- Guest session storage
- Guest order history
- Guest messages
- Menu relationships
- Guest order submission
- Realtime order updates
- Salon customization media
- Theme switching
- Existing admin/database communication
